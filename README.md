# DENOTENMAN WEBSHOP - Build with love by: MNRV

Traditionele custom webshop voor De Notenman.

## Stack

- Next.js
- TypeScript
- Supabase
- Mollie
- PostNL
- pnpm
- Turborepo

## Apps

- `apps/storefront` — publieke webshop
- `apps/admin` — beheeromgeving
- `apps/worker` — achtergrondtaken
